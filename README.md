Stock Market Forecast (Tőzsdei Előrejelző)

Egy 5 fős egyetemi projekt keretében készült webes alkalmazás, amely kiválasztott cégek tőzsdei részvényeit jeleníti meg és elemzi/jelezi előre.

## 🛠️ Tech Stack (Technológiák)
* **Backend:** Python, FastAPI, Uvicorn, Jinja2
* **Frontend:** HTML5, CSS3, JavaScript, Chart.js
* **Adatkezelés / API:** (Külső tőzsdei API-k integrációja folyamatban)
